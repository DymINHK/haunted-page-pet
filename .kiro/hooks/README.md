# Agent hooks

Hooks for this project are created in the **Kiro UI** (not hand-authored here), so the
hook definitions in this repository reflect real usage during development.

Planned hooks:
- [ ] On save of any `.ts` / `.tsx` file under `src/`: run type-check, then the unit tests
- [ ] On edit of `.kiro/specs/**`: remind to keep `tasks.md` checkboxes in sync with reality

When a hook is created in Kiro it will appear in this folder automatically.
Do not delete this README when that happens; keep it as the index of what each hook is for.
